# ZOO ARENA

2–4 ฝูงสัตว์ บนสนามป่าเดียวกัน · ทุกคนวางแผนพร้อมกัน แล้วเฉลยผลพร้อมกัน · เกมละ 3–5 นาที

## Files
- `index.html` — ตัวเกมทั้งหมด (เมนู, สอนเล่น, จัดฝูง, rig/animation, บอท, netcode ฝั่ง client). เปิดไฟล์ตรงๆ = เล่นกับบอทออฟไลน์ได้
- `server.js` — server ตัวเล็ก (bundle แล้ว ไม่ต้อง `npm install`): เสิร์ฟ `index.html` + ห้อง WebSocket. ไม่มี database — ห้องอยู่ใน memory
- `server.source.js` — source ของ server (แก้ที่นี่ แล้ว `npm run build`)
- `design/`, `prototype/` — ไฟล์ concept เดิม

## Run (LAN)

```bash
npm start          # หรือ node server.js
```

```
Zoo Arena
  Local:    http://localhost:3000
  Network:  http://192.168.x.x:3000   <- ส่งลิงก์นี้ให้เพื่อนใน Wi-Fi เดียวกัน
```

เข้าเกม → **เล่น** → ใส่ชื่อ → **สร้างห้อง** → กด *คัดลอกลิงก์ชวนเพื่อน* (ถ้าเปิดจาก localhost ลิงก์จะใช้ IP วง LAN ให้อัตโนมัติ).
เพื่อนเปิดลิงก์แล้วกด *เข้าห้อง* · ทุกคนกด *จัดฝูงของฉัน* · โฮสต์เลือกจำนวนฝูง (2 / 3 / 4) แล้วกด *เริ่มเกม*. ที่นั่งว่างเป็นบอท · 2 ฝูงจะเกิดคนละมุมตรงข้ามกัน
เล่นคนเดียวกับบอทก็เลือกได้ว่าจะเล่นกี่ฝูง

แก้ server แล้ว build ใหม่: `npm install && npm run build`

## Deploy
Node host ไหนก็ได้ (Render, Railway, Fly.io, VPS/Dokploy) หรือ Docker: `docker build -t zoo-arena . && docker run -p 3000:3000 zoo-arena`.
WebSocket ใช้พอร์ตเดียวกับ HTTP · ถ้าเป็น HTTPS จะใช้ `wss://` เอง

## สอนเล่น
หน้าแรก → *สอนเล่น (11 ขั้น)*: เป้าหมายของเกม → เดิน → ซ่อนในพุ่มหญ้า → ลองสกิลของทุกตัว → หลบให้สิงโตรอด → ล้มสิงโตศัตรู (นกฮูก แรด คาเมเลียน เต่า สิงโต หนู) · มีนิ้วชี้บอกว่าต้องกดตรงไหน ทำสำเร็จแล้วไปขั้นถัดไปเอง

## กติกา
- **เป้าหมาย: ปกป้องสิงโตของตัวเอง** — สิงโตล้ม = ทั้งฝูงตกรอบ · ล้มสิงโตฝูงอื่นให้หมด = ชนะ
- แต่ละฝูง: สิงโต (หัวหน้า) + เลือกอีก 3 จาก แรด / นกฮูก / คาเมเลียน / เต่า / หนู (ซ้ำได้ไม่เกิน 2)
- แต่ละรอบสั่งได้ **1 / 2 / 3 ตัว หรือทุกตัว** (โฮสต์ตั้งในห้องก่อนเริ่ม · ค่าเริ่มต้น 2) · เวลา 40 วิ หรือจนทุกคนกด *พร้อมแล้ว*
- เฉลยผล: ① ทุกตัวเดินพร้อมกัน (เดินชนกันเด้งกลับ) ② ลงมือ (โล่/คำราม → พุ่งชน → เฝ้ายิง → ซุ่มโจมตี → สแกน)
- สิงโตล้ม = ฝูงตกรอบ · ครบจำนวนรอบที่ตั้งไว้ (5 / 8 / 12 / 20 · ค่าเริ่มต้น 8) นับพลังชีวิตที่เหลือ

## Netcode (lockstep)
ทุกเครื่องมีสถานะเกมเหมือนกัน แล้วรัน `resolve()` ตัวเดียวกันด้วยคำสั่งชุดเดียวกัน ผลจึงตรงกันทุกเครื่อง:
1. server เปิดรอบวางแผน (`plan`) + จับเวลา · โฮสต์คำนวณคำสั่งบอทแล้วส่งขึ้นไป
2. ผู้เล่นส่งคำสั่งตัวเอง (`orders`) และกดพร้อม (`ready`)
3. ทุกคนพร้อม/หมดเวลา → server ส่งคำสั่งทั้งหมด (`resolve`) ให้ทุกเครื่องเล่น animation เอง
4. แต่ละเครื่องส่ง hash ของสถานะหลังเฉลย (`done`) · ถ้าไม่ตรงกัน server แจ้ง desync

คนหลุดกลางเกม → บอทเล่นแทนที่นั่งนั้น · โฮสต์หลุด → คนถัดไปเป็นโฮสต์ (คำนวณบอทต่อ).
เป็นแบบ trust-based เหมือน pixel-arena: client รู้ตำแหน่งทุกตัว (หมอกเป็นแค่การแสดงผล) เหมาะกับเล่นกันเองในวง LAN
